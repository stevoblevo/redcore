# Contribute

Research, not a token. Fail is a result.

## The $0 task

Photograph 20 clay bricks twice. [Full steps](protocol/experiment0.md).

1. 10 bricks from one store stack (A), 10 from another (B).
2. Same face, two days, coin in the frame.
3. Zip 40 photos + `manifest.csv` as `experiment0-yourname.zip`.
4. Open [issue #11](https://github.com/stevoblevo/redcore/issues/11).
5. Drag that **one zip** onto the comment box. Write whether you could tell A from B by eye.

If GitHub rejects the zip (~25 MB), put the folder on Drive/Dropbox as **anyone with the link can view** and paste the link. You do not need git.
